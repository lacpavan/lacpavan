## Featured Projects

### 🥊 UFC Winner Predictor
> End-to-end ML pipeline to predict UFC fight outcomes using pre-fight data.

- Temporal train/test split (train ≤ 2022 / test ≥ 2023) to simulate real-world prediction conditions
- Comparative feature engineering with fighter historical stats
- Benchmarked multiple models — `HistGradientBoostingClassifier` outperformed the Red Corner historical baseline by ~13 percentage points
- **74.7% accuracy · 0.824 ROC-AUC**
- SHAP-based explainability integrated into the inference pipeline
- FastAPI endpoint + Streamlit app deployed to production
